## Decisions Made

1. **Feathers version:** Using Bevy 0.19 with built-in `bevy_feathers` feature
2. **Coordinate system:** Using top-left origin for atlas coordinates (more intuitive for image editing)
3. **Color representation:** Using `Srgba` variant with direct field access (red, green, blue, alpha)
4. **Error handling:** Custom `FileError` enum with `From` implementations for all error types
5. **Camera:** Using `Camera2d` directly for 2D rendering
